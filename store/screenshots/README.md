Play Store screenshots - placeholders

This folder contains instructions to produce screenshots required by Google Play.

Recommended sizes and counts:
- Phone (minimum): 1080 x 1920 (vertical) — provide 4-8 screenshots.
- Tablet: 1920 x 1200 (horizontal) — optional.

Suggested screenshot list:
1. Main screen with mood selector and exercise reminder.
2. Body map with pain points selected (front view).
3. Recommendation screen showing suggested routine and button to open exercises.
4. Exercise player screen with timer visible.

Tools to create screenshots:
- Use an emulator (Android Studio) at a clean density (e.g., Pixel 3a) and capture screens.
- Or use Android Studio's "Screen Capture" feature on a connected device.

Place the final PNGs in this folder and reference them when uploading to Play Console.
